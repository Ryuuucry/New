# Vibecoded Notes

A responsive personal portfolio website for a Grade 12 ICT student.

## Pages
- `index.html` — Home
- `about.html` — About
- `interests.html` — Interests
- `journey.html` — Journey
- `reflection.html` — Reflection
- `resume.html` — Resume
- `contact.html` — Contact
- `progress.html` — My Progress

The profile photo is currently loaded from the original repository:
https://github.com/Ryuuucry/my-first-website

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.
